# 大傻豪学习翻译词典 · Yang Zihao Dic

> 划词翻译 + 生词本 + 背单词，一个浏览器扩展全搞定。
> **完全免费**，数据全在你自己电脑上，不需要注册账号，没有服务器。

由 **Yang Zihao** 开发 · 基于 [Read Frog](https://github.com/mengxi-ream/read-frog) 二次开发 · GPL-3.0

---

## 为什么做这个

市面上的翻译插件，生词本要么有条数上限，要么把你的数据存在别人服务器上，
要么核心功能藏在会员墙后面。

这个版本把这些全拆了：**生词本无上限、数据不出本机、所有功能免费**。

更重要的是补上了从「看得懂」到「说得出」那一段——查完词不是终点，
后面还有按遗忘曲线安排的复习，和逼你从零把整句英文拼出来的造句练习。

## 功能

### 翻译（不需要任何 API Key）

- **网页翻译** — 整页双语对照
- **划词翻译** — 选中即译
- **视频字幕** — YouTube 等平台边看边译
- **输入翻译** — 打中文自动转英文

默认走免费的微软 / 谷歌翻译引擎，装上就能用。

### 词典与生词本

- **划词查词** — 词条、音标、词性、释义、原句、句子翻译、CEFR 难度
- **助记** — 拆词根词缀讲清楚这个词为什么是这个意思，比死记好使
- **本地生词本** — 存在浏览器里，**没有数量上限**，可导出 CSV / JSON

> 存的是你**真实读到过**的那句原文，不是教科书例句。

### 背单词与练表达

- **闪卡复习** — FSRS 遗忘曲线算法，三种题型自动轮换
  - 听音拼写（练"听得出"）
  - 中译英（练"想得起"）
  - 语境填空（练"会用"）
- **造句练习** — 给中文，**整句英文从零拼出来**，零提示
  - 内置 **60 句日常常用表达**，装上就能练，每句都配句式讲解
  - 逐空判错：只标错的那个空，不抖答案
  - 全键盘操作
- **学习统计** — 每日学习量、连续天数、复习热力图

### 朗读

微软 Edge 语音，音质接近真人，**免费无需 Key**。

## 安装

从 [Releases](../../releases) 下载最新的 `.zip`：

1. **解压到一个固定文件夹**（之后不能删、不能移动 —— 浏览器直接从这里读取）
2. 浏览器打开 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 右上角打开**开发者模式**
4. 点**加载已解压的扩展程序**，选中解压出的文件夹

详细图文步骤见 [安装与使用说明书](安装与使用说明书.md)。

---

## 关于 API Key

**不配也能用。** 翻译、朗读、生词本、闪卡、造句练习全都不需要。

只有**划词词典**建议配一个 —— 它要生成音标、词性、释义、助记这些结构化内容，
得靠大模型。不配的话词典会自动降级成"快速模式"，只给翻译。

支持 OpenAI 兼容端点、通义千问、DeepSeek、Claude 等。
**Key 只存在你自己的浏览器里**，本项目没有服务器，不会上传到任何地方。

配置方法见[说明书第三节](安装与使用说明书.md)。
